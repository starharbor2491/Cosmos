# Data file structure (value-free)

Field names and JSON types of the `Storable*.json` files Arc writes to `~/Library/Application Support/Arc/`, extracted from a real profile with every value removed. Strings are reported only by kind (`string`, `string:url`, `string:uuid`, `string:iso-date`); identifier-like and data-derived keys are collapsed to `<uuid>`, `<id>` or `<key>`; wide maps keyed by user data are shown as `map`. `StorableAuthState.json` and `StorableFirebaseEncryptionKey.json` were deliberately skipped.
