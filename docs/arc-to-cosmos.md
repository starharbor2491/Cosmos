# Arc to Cosmos

If you used Arc every day, this is the page to keep open for the first week. **⌘/** shows the shortcut list inside Cosmos.

## Words

| Arc | Cosmos | Notes |
|---|---|---|
| Space | Space | Name, icon, theme and an optional profile. Switch with ⌃1–9 or ⌥⌘←/→. |
| Profile | Profile | A space can use its own profile with separate cookies and logins. Imported Arc profiles keep their spaces. |
| Favorites | Favorites | The same in every space, a grid at the top. ⌘1–9 jumps to one. |
| Pinned tabs and folders | Pinned | Pinned tabs go back to their home address with **Reset Pinned Tabs** (command bar). A link to another site from a pinned tab opens in Peek. |
| Today | Today | New tabs land at the top. |
| Archive | Archive (⇧⌘A) | Today tabs are archived after the interval you pick in Settings ▸ General. Search, restore or delete them. ⇧⌘T restores the last one. |
| Command Bar | Command Bar | ⌘T opens a new tab, ⌘L edits the current one. |
| Type Travel (⌃) | Command Bar commands | Type a command's name: "new space", "mute", "boosts", "set default browser". |
| Site search | Site search | Type a site's name (YouTube, GitHub, Wikipedia…) and press **Tab**. Backspace on an empty field leaves site search. |
| Peek | Peek | ⇧-click a link. ⌘O keeps the Peek page as a tab. |
| Little Arc | Probe | ⌥⌘N. Links from other apps can open here (Settings ▸ Links). |
| Split View | Split view | ⌃⇧= adds a page beside the current one, ⌃⇧- closes the focused pane. |
| Boosts | Boosts | ⌥⌘B. Colour filter, font, zoom, zap elements, custom CSS and JavaScript, per site. Arc's Boosts cannot be imported. |
| Site Control Center | Site Controls | Click the lock in the address pill: blocking for this site, zoom, Boosts, sound, permissions. |
| Ad blocking (uBlock Origin built in) | Blocking | Settings ▸ Blocking. Per-site switch in Site Controls. |
| Chrome extensions | Extensions | Cosmos ▸ Extensions…. See [extensions.md](extensions.md). |
| Auto Picture in Picture | Auto Picture in Picture | Settings ▸ General. |
| Link routing ("open links in…") | Link routing | Settings ▸ Links. |
| Hover cards, Tidy Tabs (AI), Ask on page, Easels, Notes, Live Folders, Sync, Max | — | Not in Cosmos. |

## Gestures and haptics

| Gesture | Does |
|---|---|
| Two-finger swipe sideways anywhere over the sidebar | Changes space. The list follows your fingers, resists at the first and last space, ticks when the swipe has gone far enough, and springs back if you let go early |
| Two-finger swipe sideways over a page | Back and forward |
| Pinch, or two-finger double-tap, on a page | Zoom (smart zoom) |
| Press hard on a link (Force Touch) | Opens it in Peek, like ⇧-click. Hard presses a page fakes for itself are ignored |
| Drag a tab, folder or Favorite | A small card with its icon and name follows the pointer, a marker shows where it will land, and the trackpad ticks each time the marker moves to a new place. Dropped on anything outside Cosmos, a tab arrives as its web address and nothing else |

Haptics (Settings ▸ General ▸ Trackpad haptics) are used sparingly: a tap when a drag lifts or a tab closes, a tick when something snaps (a drop marker, an opened folder, a swipe reaching its threshold), and a heavier click when something changes level (a drop lands, a space changes, a tab is pinned, favorited or split, Peek opens). On a trackpad without Force Touch they do nothing. Motion follows macOS Reduce Motion.

## Moving over, in order

1. Open Cosmos and choose **Import from Arc**. Your spaces, Favorites, pinned tabs, folders, split views and archive come across. Add Arc's history and bookmarks from the same screen.
2. **Cosmos ▸ Extensions… ▸ Find in Arc and Other Browsers** brings your extensions.
3. Pick a few Boosts you miss and recreate them (Site Controls ▸ Boost this site). Colour filters and zapping are quick.
4. Settings ▸ General ▸ **Set as default browser**, and Settings ▸ Links if you used Little Arc for links from other apps.
5. Keep Arc until 22 December 2026 if you can: its data is read, never changed, so you can import again later.
